## OKX 手續費怎麼算？

OKX 的交易費用主要按照兩個因素決定：

- 你是掛單方 Maker，還是吃單方 Taker
- 你的帳戶屬於普通用戶或哪一個 VIP 等級

掛單是指訂單沒有立即成交，而是先進入訂單簿等待撮合；吃單則是直接與訂單簿上已有的委託成交。市價單通常較容易成為吃單，但限價單也不一定都是掛單，最終仍要看成交方式。

OKX 官方費率資料顯示，標準交易對的普通用戶起始費率為：

- 掛單：0.2000%
- 吃單：0.3500%

實際費率可能因交易對分組、產品類型、帳戶地區、VIP 等級或平台規則調整而不同。下單前，應在交易頁面查看目前幣對顯示的具體費率。

例如，一筆成交金額為 1,000 USDT 的現貨交易，如果按照普通用戶吃單費率 0.3500% 計算，交易手續費約為 3.5 USDT。這只是計算示例，不代表每一個交易對都會套用同樣費率。
